Frequently Asked

A .sns subdomain is a readable Solana Name Service name under an existing .sns domain, such as yourname.mytag.sns. It can point to onchain data, especially a Solana wallet address, so compatible apps can use a name instead of a long public key. Names are first come, first served within each namespace.

SNS upgraded its naming system. Existing domains and sub-registrars now display as .sns, while keeping ownership, records, and subdomain settings. Eligible holders may also receive a matching new .sol domain later under a separate registry. For payments and identity today, use the .sns name shown in updated wallets and apps. See the SNS domain upgrade guide.

SNS names are built for payments, profiles, identity, and dApps across Solana. The official integration list includes widely used wallets and explorers such as Phantom, Solflare, Backpack, Trust Wallet, Solscan, and more. Support can differ by app, and subdomain support may differ from root .sns names, so test the exact name before relying on it for payments. See the SNS integration list and SNS usage docs.

Listed registrars currently start from 1 USDC for eligible names, plus transaction and platform fees. Some registrars may use length-based or namespace-specific pricing. Registrations are currently presented as one-time purchases with no annual renewal flow, but pricing, tiers, fees, and registrar settings can change. Always confirm the final amount on sns.id before purchasing.

After checkout, the subdomain is assigned to your wallet as an onchain SNS subdomain. Where supported, it can be used, transferred, and updated through SNS-compatible tooling. It is not the same as buying a root .sns domain: parent-domain and registrar rules still matter, and wallet support can be limited. The spelling is fixed, so if you want a different name or namespace later, register another one.

Every registration link opens an external Solana Name Service page. Wallet connection, checkout, terms, and transaction confirmation happen there, not on this page.
